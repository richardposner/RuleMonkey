# Partial-scaling test models

Validation models for the opt-in partial-scaling (PSA) acceleration path
(`set_critical_population(Nc)`; Lin, Feng & Hlavacek, *J. Chem. Phys.* 150,
244101, 2019).  Kept separate from the NFsim-oracle corpus deliberately: NFsim
has **no** partial scaling, so it is not an oracle for the scaled (`Nc > 0`)
path.  The oracles here are (1) the `nfa` prototype (network-free
RuleMonkey-method + PS, the primary scaled-path cross-check), (2) BNG2 ODE/SSA
(independent, network-based), and (3) closed-form analytic moments where they
exist.  With `Nc` unset every model runs RM's exact SSA and is byte-identical
to the ordinary engine.

## Models

### `lin2019_toy.bngl` — birth / dimerize / death

The toy system from Lin et al. 2019 (Eq. 1 / Fig. 1); the canonical PSA
validation model and the bimolecular-association batch target (plan Phase 2).

```
0        ->^k_birth  X1     zeroth-order injection
X1 + X1  ->^k_dim    X2     second-order dimerization
X2       ->^k_death  0      first-order removal
```

Intensive rate constants κ1 = 3, κ2 = 300, κ3 = 1.5 at system size Ω = 100:
`k_birth = κ1·Ω = 300`, `k_dim = κ2/Ω = 3.0`, `k_death = κ3 = 1.5`.  BNG folds
the 1/2 homodimer statistical factor into the dimerize propensity
(`.net`: `0.5*k_dim`), so the stochastic dimerize propensity is
`k_dim·N1·(N1−1)/2` — matching the `nfa` convention exactly.  The seed is the
deterministic steady state, `X1 = 10`, `X2 = 100` (so `dN1/dt = dN2/dt = 0`
there), identical to `nfa`'s `paper_toy_model(omega=100)` for direct z-tests.
Empirical stationary moments (200-rep BNG2 SSA): X1 ≈ 10 (std ≈ 2.5),
X2 ≈ 100 (std ≈ 9).

### `birth_death.bngl` — unimolecular birth-death

Immigration-death process; the unimolecular batch-fire target (plan Phase 1).

```
0  ->^k_birth  A     zeroth-order immigration
A  ->^k_death  0     first-order removal
```

`k_birth = 100`, `k_death = 1`, seeded at the stationary mean `A = 100`.  The
stationary distribution is exactly **Poisson(λ = k_birth/k_death = 100)**, so
mean = variance = 100 (std = 10) in closed form — an analytic first- *and*
second-moment oracle.  Only the unimolecular `death` rule is scalable
(`n_r = N_A`, `K = ⌊N_A/Nc⌋`); zeroth-order `birth` is never scaled.
Empirical (200-rep BNG2 SSA): A ≈ 100, std ≈ 10, confirming Poisson.

## Reference data (`reference/`)

Generated by `generate_refs.py` (BNG2 only — no NFsim):

| Path | Content |
|---|---|
| `net/<model>.net` | BNG2 reaction network (`generate_network`). |
| `ode/<model>.gdat` | BNG2 ODE trajectory (deterministic mean field). |
| `ssa/<model>.mean.tsv` | Ensemble mean over 200 BNG2-SSA reps (seeds 1..200). |
| `ssa/<model>.std.tsv` | Ensemble population std over the same reps. |

Regenerate:

```
BNG2=/path/to/BNG2.pl python3 tests/models/partial_scaling/generate_refs.py
```
